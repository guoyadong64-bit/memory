# 多源时空与过程演化超图记忆结构图

![中文结构示意图](hypergraph-memory-layered-flat.png)

最新版本按“主题索引层 → 历史经历层 → 事件与阶段层 → 事实证据层”自上向下排列，每层横向扁平展开，突出五要素经历绑定、共享条件、独立事件阶段与证据约束的联合检索，详见 [分层扁平图说明](hypergraph-memory-layered-flat.md)。下文为此前按数据字段解释的旧视角，与当前图的索引展示顺序不同。

图示按四个逻辑层展示当前记忆结构：观测与上下文、阶段经验、过程演化、任务组织。小椭圆表示节点，彩色闭合包络表示联合连接多个节点的超边；虚线显示跨层引用，箭头表示历史阶段先后。层内细线是超边成员关系的可视化投影，不表示额外创建了普通二元边。任务聚合中的“经验甲”等指记忆记录索引，不表示增加了新的节点类型。

十八类节点、八类超边是实现支持的类型数量；图中仅展示典型类型，实际实例数量随内容增长。四层不是四个数据库，完整记录、节点、超边及关联均保存在同一个 SQLite 存储中。适用条件、回答、来源及辅助存储表未全部展开。

交通内容为结构示例，阶段先后不等于因果证明；图中未表达自动事件识别、传播预测或交通控制能力。“快速判断模型”对应当前接入的 Jev。

最新版本参照用户提供的两张论文图布局，以固定坐标直接绘制 SVG，再导出 PNG。可编辑文件为 hypergraph-memory-reference-style.svg，重绘脚本为 draw_memory_reference_style.py。旧版生成图保留在同一目录。
