# 本次结构图设计说明

- 图意：用四个浅平面说明主题如何索引历史经历，经历如何关联各自的事件阶段与多源证据；彩色闭合包络显示超边的联合成员。
- 构图：结构示意主图占约四分之三宽度；右侧为简化的联合检索流程。沿用既有 Python 工作流，以 Matplotlib 输出可编辑 SVG、PDF 和 PNG。
- 视觉：白底、深蓝灰轮廓、淡紫/淡绿/淡黄超边、小型空心节点、跨层虚线；减少大文本框。参考图仅用于配色与构图，不复制其具体机制。
- 结构范围：四层为展示视图；经历甲乙是记录索引；超边完整成员可跨层，图中展示局部投影。各经历关联独立事件，不拼接彼此的行动、结果与证据。
- 设计特点：经历五要素绑定；事件内阶段先后与证据追溯；时间、空间、语义与任务共同参与检索。
- 数据性质：交通例子是结构示意，无实验数据、性能分数或因果推断。图中阶段箭头只表示时间顺序。
- 输出约定：中文文字，SVG 保留文本，PDF 嵌入字体，PNG 300 dpi。当前画布用于讨论和演示；投稿时按目标期刊尺寸单独排版，不声称已通过期刊审核。
